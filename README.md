# Тестовое задание

## Что реализовано:
- Заменил json на csv и реализовал миграции через Liquibase
- Выполнил все SQL-запросы, описанные в задаче
- Реализован `AnalysisService`, агрегирующий данные по дням и месяцам
- Сервис возвращает корректные результаты на основе предоставленных данных
- Отработана обработка ошибок через `GlobalExceptionHandler`
- Проведена ручная проверка запросов через Postman

## Архитектура:
- Java 17 + Spring Boot
- Разделение на entity, DTO, mapper, service, repository
- Использован подход `native query → Object[] → RowMapperUtil → DTO`
- Реализован унифицированный шаблон обработки запросов:
  все SQL-запросы используют одинаковую структуру параметров и возвращают данные,
  которые маппятся в DTO через вспомогательный RowMapperUtil.
